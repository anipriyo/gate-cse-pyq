# GATE CSE PYQ practice

A personal practice site for GATE CSE previous-year questions (2018 onwards), plus the scraper and database behind it.

**Live site:** https://anipriyo.github.io/gate-cse-pyq/

- **Practice:** pick subjects, topics, years, question types (MCQ/MSQ/NAT) and marks; check answers one by one (instant feedback) or see the score and solutions at the end. Optional timer, bookmarks, "redo wrong ones".
- **Mock tests:** any full paper in a GATE-style exam console: 180-minute timer, General Aptitude + CS sections, palette with GATE status colours, Save & Next / Mark for Review, on-screen keypad for NAT, scientific calculator, negative marking.
- **Results:** score with GATE marking, per-subject and per-topic breakdown, full review with solutions, a GATE Overflow link and a YouTube search link for every question.
- Progress is stored in the browser (localStorage). Use *Progress → Export* to move it between devices.

**Mac app (offline + AI tutor):** `app/` builds `GATE PYQ.app`, which runs the same site locally without internet and adds an AI tutor (✦ Hint, ✦ Explain with AI, an Ask AI chat page) backed by a local Qwen model or a ChatGPT account through Codex CLI. See `app/README.md`.

## Layout

| Folder | What |
|---|---|
| `scraper/` | `scrape_practicepaper.py` (fetch raw pages) and `build_db.py` (normalise into the database). See `scraper/README.md`. |
| `data/raw/YYYY-MM/` | Untouched JSON snapshots, one file per source page. |
| `data/pyqs.json`, `data/pyqs.sqlite` | The question database (845 questions, 13 papers in the 2026-11 snapshot). |
| `data/img/` | Figures used by questions and solutions. |
| `site/` | The static website (vanilla JS + KaTeX). `site/data/` is generated by `build_db.py`. |

## Commands

```bash
~/.venvs/analysis/bin/python scraper/scrape_practicepaper.py   # fetch new pages into data/raw/<this month>/
~/.venvs/analysis/bin/python scraper/build_db.py               # rebuild data/ and site/data/
~/.venvs/analysis/bin/python -m http.server 8765 --directory site   # preview at http://localhost:8765
```

GitHub Pages serves the `gh-pages` branch, which holds only the `site/` folder. After committing to `main`, redeploy with:

```bash
git push origin main && git subtree push --prefix site origin gh-pages
```

## Sources

Questions are from the official GATE CSE papers. Answer keys, written solutions, subject/topic tags and GATE Overflow links come from [practicepaper.in](https://practicepaper.in/gate-cse). GATE Overflow blocks automated requests, so video links are YouTube searches built from the paper name and the question's opening words. This is an unofficial tool for personal study.
